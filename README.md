# make claude your assistent - skills and plugins for that

## project vision

get everything that is needed to run claude code as 24/7 agent as personal assistant

## planned features

- claude code is running on one of your machines - all the time
- using all the software on your machine
- memory of all it needs to know/find to do your job
- connected to your email, calendar, adresses and files
  - office365,
  - gmail,
  - dropbox
- action triggered by daily, weekly timers
  - an own timer plugin, that reaches for more than 7 days
- connected by telegram to your mobile - always in your pocket

## plugins / skills

here we have plugins and skills that help "normal people" to create a claude code, that is running all the time, connected by telegram to you
